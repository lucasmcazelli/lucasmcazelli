# Lucas Cazelli

Co-founder and CPO of [North AI](https://www.north-ai.com) since March 2024. London, by way of Sao Paulo. Previously I optimized physical structures as a civil engineer. Now I optimize attention and decision-making in digital products.

The path in between: software developer in Brazil, structural and formwork engineer at PERI (finite element analysis), then product management at PERI UK, Paus (media tech) and Tes (edtech). BSc Civil Engineering. I still write production code: Python, TypeScript, SQL.

North AI predicts how people will react to a video before it is released, using AI-simulated audiences. The simulation is calibrated against real eye-tracking and EEG data.

## Projects

### Public

- [obsidian-backlink-second-brain-power-system](https://github.com/lucasmcazelli/obsidian-backlink-second-brain-power-system): builds a semantic graph across an Obsidian vault and inserts `Related: [[...]]` backlinks between notes about the same thing. Python, standard library only, a small local Ollama embedding model. No cloud calls, no vector database, no paid API. Idempotent, with a dry-run mode. One piece of a second brain I moved from NotePlan to Obsidian.
- [lucasmcazelli-gtm-skills](https://github.com/lucasmcazelli/lucasmcazelli-gtm-skills): Claude Code skills for go-to-market work. 7 orchestrator skills over 52 sub-skills (Clay, cold email, LinkedIn ads, LinkedIn content, list building, n8n, signal sourcing), plus 33 standalone skills.
- [lucascazelli.com](https://lucascazelli.com): my site. Astro on the AstroPaper theme, on Vercel. A build-time autolinker detects glossary terms and concepts across posts from a 45-term library, and an [interactive knowledge graph](https://lucascazelli.com/knowledge-graph) maps every post, concept and term. Live, source private.

### Private or not public yet

- drawload: sketch or describe a beam or truss in plain language, get back a solved, watermarked load diagram. Python FastAPI, Pynite solver, Claude text-and-vision parsing, Flutter app. Educational use only. Parked for now.
- Spider controlled by EEG: a LAFVIN quadruped robot, ESP8266 and 8 servos, driven by Emotiv EPOC X mental commands (push, pull, left, right). A Python bridge forwards them over UDP, and the ESP8266 serves its own phone control panel.
- Vault automations: agents running on my Obsidian vault. A daily standup synthesiser and a morning RSS digest with conservative backlinking.
- Engineering calculators, JavaScript, 2021 to 2023: UK wind force by postcode, formwork pressure, truss analysis on a fractal canvas, a Monty Hall simulation.
